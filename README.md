# Portfolio de Thomas

Ce projet est une vitrine web statique dédiée à un portfolio personnel de Thomas. La page présente :

- une introduction et un header visuel,
- une section d’articles récents,
- des projets mis en avant,
- un formulaire de contact,
- des liens vers les réseaux sociaux.

## Technologies utilisées

- HTML5
- CSS3
- Images au format WebP et PNG
- Polices Google Fonts : Heebo

## Structure du projet

- `index.html` : structure principale de la page
- `style.css` et `style.min.css` : feuilles de style
- `image/` : images utilisées par la page
- `styles/` : version CSS du projet (si utilisée localement)

## Utilisation locale

1. Ouvrez le fichier `index.html` dans votre navigateur.
2. Ou servez le dossier avec un simple serveur local si vous souhaitez tester les chemins d’assets de manière plus réaliste.

## Déploiement

Le site est compatible avec GitHub Pages. Assurez-vous que les fichiers HTML et CSS ainsi que le dossier `image/` sont présents dans la branche utilisée pour le déploiement.

## Objectif

Ce projet sert de base pour présenter un profil créatif ou graphique de manière moderne, claire et responsive.
